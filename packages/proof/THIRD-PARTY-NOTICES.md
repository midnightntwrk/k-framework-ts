## K Framework (pyk)

This package is a hand-transcription of pyk's proof artifact layer at K
`v7.1.337` (commit `4a46d1231473b599c699160132fd6e76a5c46406`). The exact
implementation and behavioral-oracle files, their hashes, and the reason each
is in scope are machine-readable in `src/version.ts` as `TRANSCRIBED_FROM`.
They are `pyk/src/pyk/proof/{proof,reachability,implies}.py` and the upstream
proof unit tests. Three helpers `APRProof` needs are transcribed from
`pyk/src/pyk/kcfg/kcfg.py` into `src/rules.ts`, because this workspace models a
KCFG edge as data rather than as an object with methods. `pyk/src/pyk/proof/
prove_rpc.py`, `show.py`, and `tui.py` are deliberately not transcribed.

`fixtures/pinned-pyk-proof.json` is generated by running pyk itself
(`fixtures/generators/generate-pinned-pyk-proof.py`) and therefore contains
JSON documents pyk produced. `fixtures/upstream/kontrol/` contains unmodified
files from `runtimeverification/kontrol`, which is also BSD 3-Clause; see
`fixtures/PROVENANCE.md` for commit, paths, and per-file hashes.
