# Third-party notices

## GNU Bison

This package invokes GNU Bison as an external tool and decodes its XML report.
GNU Bison is not bundled with this package. The V1 adapter was conformance
tested against GNU Bison 3.8.2.

## @xmldom/xmldom

`@xmldom/xmldom` parses Bison's XML report at runtime. Its own license and
notices are supplied with that dependency.
